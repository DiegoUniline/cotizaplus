# Glosario

| Término | Significado en Cotizaplus | Certeza |
|---|---|---|
| Empresa | Negocio que renta Cotizaplus; sus datos están separados de las demás | ✅ P-001 |
| Super-admin | Dueño de la plataforma; administra todas las empresas | ✅ P-013 |
| Dueño | Usuario principal de una empresa; maneja plan, pago y usuarios | ✅ P-007 |
| Gerente | Usuario que ve y edita todo en su empresa y autoriza descuentos | ✅ P-007 |
| Vendedor | Usuario que solo ve sus propios clientes y cotizaciones | ✅ P-007 |
| Cliente | Persona o empresa a la que una empresa le cotiza | ✅ |
| Cliente final | Lo mismo que cliente, visto desde la liga pública | 🟡 |
| Cotización | Documento con partidas y totales que se envía al cliente | ✅ |
| Partida | Renglón de la cotización: imagen, descripción, atributos, serie, tipo de cobro, cantidad, precio | ✅ P-008 |
| Tipo de cobro | Forma en que se cobra una partida: pago único, mensual o por hora | ✅ P-008 |
| Atributo | Campo que define cada empresa para sus productos (Color, Medida, Modelo…) | ✅ P-009 |
| Número de serie | Identificador de la pieza; se captura al cotizar | ✅ P-009 |
| Folio | Número consecutivo de la cotización | 🟡 prefijo propio por empresa 💡 |
| Liga pública | Dirección web donde el cliente ve, acepta (con firma) o rechaza la cotización sin cuenta | ✅ P-010 |
| Visto | Momento en que el cliente abre la liga pública | ✅ P-010 |
| Bitácora | Registro de cada contacto con el cliente y siguiente paso | ✅ P-011 |
| Kanban | Tablero con una columna por estado donde se arrastran cotizaciones | ✅ P-011 |
| Recordatorio | Mensaje automático al cliente sobre una cotización pendiente | ✅ P-011 |
| Resumen diario | Correo al vendedor con sus seguimientos del día | ✅ P-011 |
| Paquete de WhatsApp | Saldo de mensajes automáticos que la empresa compra aparte | ✅ P-011 |
| Plan | Básico, Pro o Empresa | ✅ P-004 |
| Prueba | Periodo gratis al registrarse | ✅ P-006 |
| Pedido | Documento con folio propio que se genera al aceptar una cotización | ✅ P-014 |
| Plantilla | Diseño de PDF que la empresa elige | ✅ P-015 |
| Vigencia | Fecha hasta la que es válida una cotización | 🟡 |
| MRR | Ingreso mensual recurrente de la plataforma | ✅ P-013 |
